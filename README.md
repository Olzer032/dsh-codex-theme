# Codex Theme for DSH

一个为 DeepSeek Harness Web 界面提供 OpenAI Codex 配色的主题插件。

颜色取自运行中的 Codex 桌面应用实测值，通过 DSH 官方的主题扩展点 `ctx.theme.overrideTokens` 实现，共覆盖 118 个 `--dsw-*` token（明暗双模式）。不接管宿主组件，不使用哈希类名选择器。

---

## 安装

```bash
# 在你的 DSH profile 目录下
pnpm add dsh-codex-theme
```

然后把 `dsh-codex-theme` 加入 profile 的 `dsh.profile.bundles` 列表。

装好后：

| 位置 | 内容 |
|---|---|
| 设置 → Codex 主题 | 开关、配色选择、界面预览、自定义参数编辑器 |
| 设置 → 通用 | 一行式开关 |

关闭开关即可卸载 token 层，界面回到原主题，无需重启。

## 功能

**配色预设**

| 预设 | 定位 | 深色 surface / ink / accent |
|---|---|---|
| Codex | 出厂默认，实测值 | `#181818` / `#ffffff` / `#339cff` |
| Codex Dim | 较低层次对比 | `#202124` / `#e8e9ea` / `#6fb6ff` |
| Codex High Contrast | 较大分离度 | `#0d0d0f` / `#ffffff` / `#4da3ff` |
| Codex Slate | 冷调中性灰 | `#1a1f27` / `#eef2f7` / `#5ea0f0` |
| Codex Warm | 暖调中性灰 | `#1f1b17` / `#f5efe7` / `#e0a06a` |

Codex 的外观设置由 Theme（浅色/深色/跟随系统）与四个参数（accent、surface、ink、contrast）共同决定，全部 CSS 变量由这四个值推导。上面五组预设是同一参数模型下的五组取值，默认值来自 Codex 应用内的实际配置：

```js
dark:  { accent:'#339cff', contrast:60, ink:'#ffffff', surface:'#181818' }
light: { accent:'#339cff', contrast:45, ink:'#1a1c1f', surface:'#ffffff' }
```

**自定义**

第六张卡片打开参数编辑器，浅色与深色各自独立，可调整：

| 参数 | 控件 | 范围 |
|---|---|---|
| 强调色 | 取色器 | `#rrggbb` |
| 背景 | 取色器 | `#rrggbb` |
| 前景 | 取色器 | `#rrggbb` |
| 对比度 | 滑块 | 0–100 |

改动任意一项会自动切到「自定义」。非法颜色（非 `#rrggbb`）与损坏的存储数据会回落到默认值。底部「恢复为实测值」清空自定义并回到 Codex 预设。

## 实测色值

浅色与深色两套值均取自运行中的 Codex 应用：

| 元素 | 浅色 | 深色 |
|---|---|---|
| 对话区 | `#FFFFFF` | `#181818` |
| 侧栏 | `#F3F3F3` | `#202020` |
| 用户气泡 | `#F3F3F4` | `#222222` |
| 弹层/菜单 | — | `#2D2D2D` |
| 正文 | `#1A1C1F` | `#FFFFFF` |
| 次级文字 | `#6E7072` | `#B4B4B4` |

代码块：

| | 浅色 | 深色 |
|---|---|---|
| 背景 | `#F2F2F2`（低于页面） | `#2A2A2A`（高于页面） |
| 语法·字符串 | — | `#F9DC78` |
| 语法·数值 | — | `#F1A275` |

其他：

| 元素 | 值 |
|---|---|
| 发送按钮（深色） | `#8B8B8B` 灰盘 + 深箭头 |
| diff 新增标记 | `#00A240` |

几处实测与直觉不同的地方，已在实现中处理：

- 侧栏与对话区的明暗关系在两种模式下方向相反。浅色下侧栏更暗，深色下侧栏更亮。
- 代码块背景同理：浅色下沉，深色抬升。
- 语法配色由主题驱动，并非固定五色。
- 侧栏、用户气泡、代码块头部共用同一个表面色值。

原始记录与截图见 [`codex-ui-reference/`](../codex-ui-reference/)。

## token 覆盖范围

| 类别 | 数量 |
|---|---|
| 别名色（表面 / 文字 / 边框 / 状态） | 87 |
| 特定面（侧栏 / 气泡 / 菜单） | 11 |
| 语法高亮（shiki） | 9 |
| 圆角阶梯 | 6 |
| 静态卡片面 | 4 |
| 焦点环 | 1 |
| **合计** | **118** |

每个值都以 `{ light, dark }` 成对声明。切换预设时，`buildTokens` 先把该预设的四项参数代入 `paletteFromPreset` 生成表面色阶，再求值 token 表，因此上表结构在五套预设间一致，只有数值不同。

## 未覆盖的部分

以下内容不在本插件范围内：

- 布局结构（侧栏宽度、单列居中、提示符样式）
- 壁纸、毛玻璃、透明度、字体替换
- 推理强度控件
- 宿主组件中硬编码的颜色（图表等）

工具调用卡片尚未实测取色，需要工具执行中的会话才能进行。

视觉效果的最终观感需人工确认：DSH Web GUI 需要会话认证，无法在无头环境中截图，改动通过 token 注册表与渲染树模拟验证。
